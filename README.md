# Portfolio

Personal portfolio of Onkar Khairnar, built with Vite + React and deployed to GitHub Pages.

Live: https://OnkarKhairnar.github.io/Portfolio/

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Edit content

All text lives in `src/data/` (profile, skills, education, projects). Components only render it.

## Deploy

Push to `main`. In the repo go to Settings > Pages > Source and choose **GitHub Actions**.
